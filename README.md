# Factory Game

一款使用 Godot 4.7 和 GDScript 开发的平面 2D 流水线工业游戏。

## 当前状态

- 已完成基础摄像机系统。
- 使用 `W`、`A`、`S`、`D` 浏览 5120 × 2880 的测试地图。
- 摄像机被限制在地图范围内。
- 已建立 32 × 32 像素、160 × 90 单元的整数逻辑网格。
- 鼠标悬停时显示当前单元格，网格提供世界坐标互转与边界判断 API。
- 鼠标滚轮可在 0.5×–2.5× 范围内以指针位置为中心缩放地图。
- 按住鼠标中键拖动可平移地图。
- 已接入 1×1 测试建筑：左键连续放置，右键或 Esc 取消，B 重新进入放置模式。

## 运行

1. 使用 Godot 4.7.x 打开本目录中的 `project.godot`。
2. 运行项目；主场景为 `scenes/main/main.tscn`。

## 目录

- `docs/`：设计、架构和任务文档。
- `scenes/`：Godot 场景，按系统职责分类。
- `scripts/`：GDScript 代码，按系统职责分类。
- `data/`：物品、配方和机器的数据定义。
- `assets/`：纹理、音频和字体资源。
- `tests/`：自动化与回归测试。
- `builds/`：本地导出产物，不提交到 Git。
- `tools/`：项目开发工具，例如固定版本的 Godot MCP。
