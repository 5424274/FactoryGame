# 游戏设计

## 核心目标

玩家在二维网格地图上建造生产机器和物流设施，将原料加工为产品，并通过扩建和优化提高整条流水线的吞吐量。

## 核心循环

1. 获取或生成原料。
2. 放置机器与传送设施。
3. 配置生产配方。
4. 观察物流瓶颈。
5. 调整布局并扩大生产规模。

## 当前原型范围

- 1280 × 720 的设计视口。
- 5120 × 2880 的测试地图，即宽高各为视口的 4 倍。
- 使用 32 × 32 像素的逻辑网格，共 160 × 90 个可用单元。
- 使用浅灰网格地面和随机铁矿地块作为原型地图表现。
- 使用 `W`、`A`、`S`、`D` 移动视角。

## 首个可玩版本

- 网格地图和摄像机。
- 建筑放置、旋转和拆除。
- 原料箱、传送带、加工机器和成品箱。
- 一条能够持续运行的完整生产链。
- 简单库存界面及保存/读取。
